# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- ローカルリポジトリ：自分のパソコン内にあるリポジトリ。
- リモートリポジトリ：GitHubなどのサーバー上にあるリポジトリ。チームで共有したり、バックアップとして利用したりする場所。

## プッシュとマージの違いは何でしょうか？
- プッシュ：ローカルリポジトリで行ったコミットをリモートリポジトリに反映すること。
- マージ：別のブランチで行った変更内容を現在のブランチに取り込むこと。

## コミットとプッシュの違い
- コミット：ローカルリポジトリに変更内容を記録すること。
- プッシュ：ローカルリポジトリに記録したコミットをリモートリポジトリに反映すること。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- コミットメッセージは、どのような変更を行ったのかが分かる内容を簡潔に記載するのが望ましい。
- 「修正」や「変更」だけではなく、具体的な内容を記載する。
- 例：スマホサイズでトップへ戻るボタンを表示するよう修正


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージするフローは、自分のパソコン上で実行して、ブランチを統合する方法。
- プルリクエストでマージするフローは、GitHub上で変更内容をレビューしてもらい、承認後にマージする方法。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- まず、どのファイルでコンフリクトが発生しているかを確認する。
- コンフリクトが発生した箇所を開き、どの内容を残すべきか判断して修正する。
